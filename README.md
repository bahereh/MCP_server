# MCP_server

A lightweight **Model Context Protocol (MCP) server** for querying service transaction records from an Oracle database.

This server exposes tools that allow LLM agents or MCP-compatible clients to retrieve structured service data such as user transactions, payment details, and timestamps.

Built with **FastMCP** and designed for research and experimentation with AI-assisted data analysis.

---

## Features

- MCP-compatible server
- Oracle database integration
- Structured data retrieval
- Built-in input validation
- Secure file path handling
- Logging for debugging and monitoring

---

## Tech Stack

- Python
- FastMCP
- SQLAlchemy
- Pandas
- OracleDB driver
- python-dotenv
